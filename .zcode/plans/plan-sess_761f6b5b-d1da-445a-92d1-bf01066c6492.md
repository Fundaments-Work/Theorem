1. **Research summary** — Supertonic 3 (99M params, 31 languages in one shared multilingual model, per-voice files 292KB, fp32 assets ≈ 400MB: duration_predictor 3.7MB / text_encoder 36.4MB / vector_estimator 257MB / vocoder 101MB, 44.1kHz PCM out); code MIT + weights OpenRAIL-M (mirroring compliant); upstream archived July 2026 → fork-hosting is permanently stable; int8/WASM/WebGPU rejected after real-world testing (laggy demo); fp32 proven on phones (Play Store app + ouor/supertonic-android ship the fp32 set; 257MB vector estimator is memory-mapped, denoise steps tunable for low RAM).

2. **Desktop engine** — Rust `ort` (`load-dynamic`) + onnxruntime dylib downloaded at first use from `fundaments-work/supertonic-assets` releases (nothing ships); SHA-256-verified download layer (clone of the dictionary-download machinery with progress events); sentence-chunked synthesis pipeline (duration predictor → text encoder → vector estimator → vocoder → 44.1kHz f32 PCM); content-hash cache (instant resume/replay, LRU ~1GB) + next-page prefetch for zero-gap audiobook feel; desktop immersion reader becomes full replacement once installed.

3. **Android — own companion engine app (decided)** — fork brahmadeo's FOSS Supertonic engine app as "Theorem Neural Voice" under `fundaments-work`, with model downloads pointed at the `supertonic-assets` repo; Theorem enumerates installed TTS engines, recommends this one with a direct install link, and selects it via `TextToSpeech(context, listener, enginePackage)`. **Documented caveat (explicitly requested): Android users must install this separate companion app** — required because Android 10+ blocks loading downloaded native runtimes (no runtime-download path) and no ONNX runtime is bundled, keeping the 38MB APK unchanged. Without the companion app, Android keeps the current platform voice. Also document the bug that motivated this: the current plugin binds the system-default engine once and caches it, so engine switching silently fails today. Bonuses: `onRangeStart` word boundaries (true per-word highlighting) and `synthesizeToFile()` (used for audiobook generation with any engine).

4. **Save-as-Audiobook** — batch-synthesize per chapter (desktop: Supertonic; Android: `synthesizeToFile` with the selected engine) → Ogg Opus via native libopus (~300KB dep; MediaRecorder rejected — encodes at 1× realtime) → ~15-20MB/hour → chapter files + marks stored in the existing `BookAudioTrack` schema → playable by the companion player. Background generation with progress/cancel.

5. **Phase ordering** — Phase 1: engine (desktop download+inference, Android engine selection in the plugin); Phase 2: companion playback per the existing design (unchanged); Phase 3: generation integrated (Save-as-Audiobook). ImmersionPlayer/Bar rewrite details (real audio, voice picker, speed, download/engine prompts).
