# Companion Audiobooks

Theorem attaches **human-narrated audiobook audio directly to books** — no
separate app, library tab, or server. A DRM-free `.m4b`, `.m4a`, or `.mp3`
file can be linked to any book, and the reader's immersion mode upgrades from
synthetic TTS into a full audiobook player. Audiobooks can also be
**generated** from an open book with the neural voice
([tts.md](tts.md)).

## Attaching Audio

Book context menu (library) → **Attach Audiobook...** → pick an
`.m4b`/`.m4a`/`.mp3` file. The Rust command `extract_audiobook_metadata`
(`src-tauri/src/audiobook.rs`) parses duration, title, author, cover art and
chapter markers in milliseconds:

- **M4B/M4A**: tags and artwork via `mp4ameta`; chapters come from a
  hand-rolled QuickTime chapter-track walker (the `udta.chap` reference →
  stts/stsc/stsz/stco sample-table expansion → 2-byte-length-prefixed text
  samples) because no crate exposes them.
- **MP3**: ID3v2 `CHAP`/`CTOC` frames via `id3`. Files with no ID3 tag at all
  attach normally (no title, no chapters). Duration is read without decoding:
  the Xing/Info or VBRI frame count for VBR files, otherwise audio bytes ÷
  bitrate for constant bitrate (ID3v2 prefix and ID3v1 suffix excluded); the
  last chapter end is only a fallback, and the player still corrects it from
  the decoded audio.

The result is stored on the book as an optional `audioTrack: BookAudioTrack`
(`filePath`, `format`, `durationSec`, `currentPositionSec`, `playbackSpeed`,
`chapters[]`) in the library store — so it **syncs to paired devices via
iroh** alongside the rest of the book record. The path is device-specific:
on a device where the file does not exist the player says so (see below)
instead of staying silent. **Detach Audiobook** removes the link. If the file
was generated by Theorem it is deleted too (`delete_generated_audiobook`,
which only ever deletes inside `app_data_dir()/audiobooks`); an attached
recording from anywhere else is never touched. Deleting the book, or replacing
its recording with a different file, cleans up the same way.

## The Player

Opening a book with an attached track and toggling immersion mode swaps the
reader's TTS row for `src/features/reader/audio/AudiobookBar.tsx`:

- Streaming playback from the local file via `HTMLAudioElement` through the
  Tauri asset protocol; container duration is replaced by the real decoded
  duration once known.
- Scrubber over the actual duration (click, drag, or arrow keys / Home / End
  when focused), ±15s skip buttons, speed chips (0.75–2×, `aria-pressed`),
  chapter menu with jump-to-chapter, sleep timer (15/30/45 min, or end of
  chapter). End-of-chapter stops at the chapter boundary position, so playback
  speed cannot make it overshoot; the minute timers are wall-clock.
- Position auto-save throttled to 5s plus pause, end and unmount, persisted
  into `audioTrack.currentPositionSec` (synced). Nothing is saved before the
  file has loaded, so closing the player early cannot reset the position to 0.
  A recording left within 3s of the end starts over on the next open.
- A file that cannot be played (moved, missing on this device, or a format the
  platform webview cannot decode) shows a message in the bar and disables Play
  rather than leaving a dead button.
- `navigator.mediaSession` metadata and action handlers for lock-screen and
  headphone controls (play/pause, seek backward/forward).
- Platform/neural TTS narration is stopped automatically while the audiobook
  player is active.

## Save as Audiobook (desktop)

With the Neural Voice installed, the immersion bar offers **Generate
Audiobook**: the foliate engine extracts the text of every section worth
narrating (`getAllSectionsForAudio` → `engines/audio-sections.ts`), and `generate_audiobook`
(`src-tauri/src/audiobook_gen.rs`) narrates the whole book in a detached task:

- Chapters are named from the table of contents: each spine section takes
  the deepest TOC entry pointing at its start (else the first entry pointing
  into it), then its first heading, then "Section N"; a file the TOC does not
  list and that has no heading continues the previous chapter (split
  chapters). Non-linear items (`linear="no"`), the navigation document, a
  contents or cover page named in the landmarks/guide, the cover and pages
  that are only an image are skipped. Paragraph breaks are kept so headings
  and paragraphs end a sentence.
- Reuses the Supertonic sentence chunker and WAV cache; joins chunks with
  0.3s gaps. Text is normalised for the book's language, and cancel is checked
  before every chunk, not just every section.
- Resamples 44.1kHz → 48kHz and encodes **Ogg Opus** at 36kbps mono
  (~16MB per finished hour) via libopus (`audiopus`, static vendored build,
  desktop-gated) with a hand-rolled Ogg page muxer (Ogg CRC, covered by unit
  tests). The stream follows RFC 7845: `OpusHead`, an `OpusTags` packet with a
  vendor string **and** the user-comment count (decoders reject it without),
  pages closed before the 48-packet or 255-segment limit, and always a final
  page carrying the end-of-stream flag.
- Output: `app_data_dir()/audiobooks/<book-id>.ogg` with chapter marks
  returned as `AudioChapter[]`; emitted via
  `audiobook-gen-progress` / `audiobook-gen-done` events (carrying the book id;
  the reader only reacts to its own book) and cancellable per book. The
  immersion bar shows a Cancel button while generating
  (`generate_audiobook_cancel`). Any failure or cancel removes the partial
  `.ogg.part` file. Book ids are restricted to `[A-Za-z0-9_-]` because they
  become file names.
- On completion the generated file is attached as the book's `audioTrack`
  (format `opus`) and immediately playable by the companion player.

Android generation (batch `synthesizeToFile` through the selected engine) is
deferred until Theorem Neural Voice ships; generation commands return a
desktop-only error there.
