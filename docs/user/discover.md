# Discover Free Books

Browse and search public-domain books from Project Gutenberg and Standard Ebooks, and add them to your library with one click.

Discover is available in the desktop apps. It is not part of the Android app. It needs an internet connection to load new sections and to download books.

## Open Discover

Click Discover in the sidebar, the compass icon near the bottom of the icon list. There is no keyboard shortcut for this page.

The page opens on a storefront. At the top is a featured book labeled Featured Classic, and below it are rows of books in sections:

- Timeless Essentials
- New & Restored Editions
- Philosophy & Essays
- Classic Fiction

Most sections come from Project Gutenberg. New & Restored Editions comes from Standard Ebooks. Scroll a row sideways to see more books.

Theorem remembers the last sections it loaded, so the page still shows them if your connection drops. Click the refresh button (Refresh catalog) to load them again. If nothing can be loaded and nothing is cached, the page says "Could not connect to online libraries" and offers a Try Again button.

## Search for a book

1. Click the search box, which reads "Search 75,000+ classics, authors, subjects…".
2. Type at least two characters. Results appear after a short pause.
3. Scroll through the results grid.
4. Click Clear Search, or empty the box, to return to the storefront.

Search looks through the Project Gutenberg catalog. If it finds nothing, the page says so and suggests searching by author, title or topic.

## Add a book to your library

1. Click a book, or click View Book on the featured book. A detail window opens with the cover, title, author and description.
2. Click Add to Library.
3. Wait for the download. A message at the corner tracks the steps and then confirms that the book is in your library.
4. Open the book from the Library page. Once a title is in your library, Read Now in the detail window opens it directly.

Theorem downloads the EPUB version when one is offered. If a title has no direct download, you see an error message instead. Books without a cover get a plain dark generated cover with the title and author.

## Sources you add yourself

The Discover page has an Add Source button where you can enter a name and an OPDS catalog address, such as a Calibre server on your network. In the current version this guide could not confirm a screen where saved sources are listed or browsed, so it does not cover them. Use the Library page to add books from your own server by downloading the files and importing them. See [Library and import](library-and-import.md).
