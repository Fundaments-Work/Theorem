## 1. Executive Strategy & Guiding Decisions

Theorem's roadmap from **v1.5.5 to v1.6.0** is focused on **rock-solid stability, native performance parity, and universal knowledge extensibility**:

### 1.1 Fast Reading vs. Bionic Reading Clarification
- **Fast Reading Mode (RSVP / Speed Read - Built-in)**: Theorem already includes an RSVP (Rapid Serial Visual Presentation) mode in `src/features/reader/components/SpeedReaderModal.tsx`. RSVP flashes words sequentially at a fixed visual point at 300–800+ WPM, eliminating saccadic eye movement. This feature is preserved and accessible via reader controls.
- **Bionic Reading (Dropped from Roadmap)**: Bionic reading alters page typography by bolding the initial syllables of every word (e.g., **The**orem **del**ivers **fas**ter **read**ing). Because Theorem readers value clean, unadorned typography and Theorem already has RSVP speed reading, artificial font bolding adds visual clutter without verifiable comprehension benefits. It is removed from the roadmap.

### 1.2 Spaced Repetition: Theorem Lemma SRS vs. Anki Exporter
- **Lemma SRS Integration**: Theorem's vocabulary workspace already synchronizes terms and definitions with **Lemma**, our companion spaced-repetition tool.
- **No Redundant Anki Exporter**: Rather than building an isolated Anki `.apkg` generator that fragments development focus, vocabulary and highlights are exported as clean, standard Markdown that any flashcard tool or the Lemma plugin can consume directly.

### 1.3 Universal PKM / Markdown Systems (De-biasing from Obsidian)
- Theorem is not an "Obsidian-only" reader. It is the premier reading hub for **all Markdown-based Personal Knowledge Management (PKM) systems**, including **Obsidian, Logseq, Foam, SilverBullet, Anytype, Dendron, Joplin, and plain Neovim/Emacs directories**.
- All note and highlight exports use standard Markdown, standard YAML frontmatter (`---`), and portable callouts (`> [!note]`, `> [!quote]`). In **v1.6.0**, a native template compiler will let users format their notes according to any tool's preferred schema.

## 3. Comprehensive Feature Audit & Stabilization Matrix (v1.5.6 → v1.6.0)

A systematic audit across all Theorem subsystems reveals the following areas requiring stabilization and edge-case handling:

### 3.1 PDF Engine (`src/features/reader/engines/pdfjs-engine.tsx`)
- [ ] **Full Virtualizer Geometry**: Replace incremental batch-appending (`pages` state array) with a pre-computed layout index (`pageLayout: Array<{ pageNumber, top, height, width }>`).
- [ ] **Scrollbar Accuracy**: Ensure container `scrollHeight` reflects the complete document from initial mount.
- [ ] **Two-Page Spread View**: Implement `two-page` presentation mode alongside `scroll` and `paged`.
- [ ] **Pinch-to-Zoom Stability**: Eliminate visual canvas resets during trackpad pinch; apply CSS hardware scale transform until zoom gesture settles.
- [ ] **Search Match Ringing**: Render active highlight rectangles on the visible text layer for search results.
- [ ] **PDF Outline Tracking**: Synchronize the Table of Contents active item with the current visible page during continuous scroll.

### 3.2 EPUB & Reflowable Engine (`src/features/reader/foliate-js-runtime/`)
- [x] **Null Safety**: Guard `paginator.expand()` and `uncollapse()` against null document element and non-object anchors (fixed in commit `9c7d18e`).
- [x] **Client Rect Filtering**: Multi-column SVG highlight overlayer strictly uses `Range.getClientRects()` to avoid column gutter rectangles (fixed in v1.5.5).
- [ ] **Touch Drag-Selection Boundary**: Improve edge-drag scrolling on mobile touchscreens when extending a highlight across page turns.
- [ ] **Theorem Lens Footnote Placement**: Ensure peek popovers (`FootnotePopover.tsx`) calculate boundary margins cleanly when tapped near the bottom-right viewport edge.
- [ ] **Font & Spacing Persistence**: Verify per-book overrides properly fall back to global settings store without layout re-flow jitter.

### 3.3 Peer-to-Peer Sync & File Transfer (`src-tauri/src/file_transfer.rs`, `iroh_sync.rs`)
- [x] **Multi-Mount Scope**: Extended Tauri asset protocol to support external backup and removable drives (`/run/media/**/*`, `/media/**/*`, `/mnt/**/*`) (fixed in commit `9c7d18e`).
- [x] **Library Storage Key Support**: Updated `FileTransferHandler::find_in_db` to support `zustand:theorem-library` alongside legacy `persist:theorem-library` (fixed in commit `9c7d18e`).
- [x] **Direct Socket Fallback**: Stored `remote_ip` and `remote_port` from QUIC connection paths for offline LAN file transfers (fixed in commit `9c7d18e`).
- [x] **Last Read Reading Progress Sync**: Removed premature bailout in `provisionToIrohDocs`, ensuring reading position updates propagate across Iroh gossip within 2 seconds (fixed in v1.5.5).
- [ ] **Offline Conflict Merging**: Refine in-Rust SQLite gossip merge (`sqlite_merge_sync_entries`) to handle concurrent bookmark and note additions on different devices without overwriting.
- [ ] **Missing Mount User Alert**: When an external drive book is opened while the drive is unmounted, display a clear "Drive Not Connected" indicator instead of a generic failure.

### 3.4 Mobile Experience (Android)
- [x] **TTS Engine Safety**: Added Kotlin null-safety checks around `currentTts.voices` in `TtsAudioPlugin.kt` (fixed in v1.5.5).
- [x] **Mobile Immersion Accessibility**: Defaulted TTS enabled and exposed voice/speed popovers on mobile (fixed in v1.5.5).
- [ ] **Android Hardware Back Button**: Wire Tauri back button event to cleanly close active modals, search panels, and the reader before triggering app exit.
- [ ] **Background Audio Focus & Lockscreen**: Bind native Android `MediaSession` and request audio focus in `TtsAudioPlugin.kt` so speech continues when the screen locks.
- [ ] **Touch Zone Tuning**: Refine tap-target boundaries on portrait phones: center 50% toggles bars, left 25% turns back, right 25% turns forward.

### 3.5 Personal Knowledge Management (PKM) Export (v1.6.0 Target)
- [x] **Single-Shot Rayon Export**: High-performance multi-threaded export engine in Rust (`vault_export.rs`) capable of writing 10,000 notes in <50ms.
- [ ] **Customizable Mustache/Jinja Template Engine**: Expose customizable templates in Settings → Devices & Export for frontmatter, quote callouts, and notes.
- [ ] **Universal PKM Presets**: Out-of-the-box presets for Obsidian, Logseq, Foam, SilverBullet, Anytype, and Joplin.
- [ ] **Automated Webhooks**: Event-driven HTTP dispatch for pushing annotations to Readwise, Notion, and custom endpoints.

## 5. Quality Gates & Verification Protocol

Before any release or merge:
1. **Zero TypeScript Errors**: `pnpm typecheck` must pass with 0 errors.
2. **100% Passing Tests**: `pnpm test` (all unit, integration, and performance suites) must pass cleanly.
3. **Zero Rust Warnings**: `cd src-tauri && cargo fmt --check && cargo clippy && cargo check` must produce 0 warnings and 0 diffs.
4. **Security & Secrets Compliance**: Strict zero-credential policy per `AGENTS.md`. No secrets or environment variables accessed or committed.
5. **No Release Without Confirmation**: All beta and stable tags are built and validated locally, requiring explicit user review before pushing to `origin/main` or tagging GitHub releases.
