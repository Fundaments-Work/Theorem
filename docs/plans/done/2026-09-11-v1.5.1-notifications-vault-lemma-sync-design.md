# Design Spec: Theorem v1.5.1 — Notifications, Automatic Vault Sync & Lemma Flashcards

**Status**: Approved
**Target Release**: v1.5.1
**Date**: 2026-09-11

---

## 1. Objectives

1. **Non-Intrusive, Reliable Notifications**:
   - Eliminate nagging "You're X min short" toasts when closing a book or navigating away from the reader.
   - Lock the daily goal achievement notification so it fires **strictly once per day**.
   - Fix the daily 8 PM reminder so it runs globally across the entire app and reliably reminds users if their goal is unmet (including 0 minutes read).
2. **Seamless Automatic Vault Sync ("Set-and-Forget")**:
   - Automatically trigger an initial full export immediately upon selecting a vault folder.
   - Maintain a 2-second debounced background sync on all highlight, note, and vocabulary mutations.
   - Clean, idiomatic Obsidian folder layout under a dedicated `Theorem/` root.
3. **Lemma Spaced Repetition (FSRS) Deck Export**:
   - Structure `Theorem/Vocabulary.md` with frontmatter `tags: [flashcards]` and Lemma `---card--- ^fsrs-...` block syntax.
   - Ensure Lemma automatically detects the file as a deck and indexes every word with in-book context while preserving FSRS review history.

---

## 2. Notification Architecture

### 2.1 Removing Book-Close Shortfall Alerts
- In `src/features/reader/hooks/useReadingTime.ts`, remove the cleanup hook block that executes `notifyGoalShortfall(...)`.
- Exiting the reader now flushes reading time and updates streaks completely silently.

### 2.2 Deduplicating Daily Goal Reached Celebration
- Add `lastGoalNotifiedDate?: string` to `ReadingStats` in `src/core/types/index.ts` and `src/core/store/settingsStore.ts`.
- When `flushReadingTime` calculates `todayMinutes >= dailyGoal`:
  - Check `stats.lastGoalNotifiedDate !== today`.
  - If not notified today, trigger `notifyGoalMet(dailyGoal)` and call `updateStats({ lastGoalNotifiedDate: today })`.
  - Subsequent flushes or re-entering the reader on the same day will no-op.

### 2.3 Global 8 PM Daily Reminder
- Move `useDailyGoalReminder()` from `src/features/reader/Reader.tsx` into `src/App.tsx`.
- In `src/features/reader/hooks/useDailyGoalReminder.ts`:
  - Allow reminder when `result.today_minutes < result.daily_goal` (removing the `today_minutes > 0` condition so it fires if the user hasn't opened a book).
  - Track `lastDailyReminderDate?: string` in `settingsStore` to guarantee at most one reminder per calendar day.
  - Evaluate whether current time is within a $\pm 10$-minute window of `settings.dailyReminderTime` (default `20:00`).

## 3. Vault & Lemma Sync Architecture

### 3.1 Idiomatic Folder Hierarchy
Instead of scattering files across the vault root, Theorem exports into a unified folder:
```text
<VaultRoot>/
└── Theorem/
    ├── Vocabulary.md        # Single Lemma FSRS Flashcard Deck
    └── Books/               # One note per book/article
        ├── Dune - Frank Herbert.md
        └── Clean Code - Robert C. Martin.md
```

### 3.2 Lemma Flashcard Deck (`Theorem/Vocabulary.md`)
Formatted specifically for the Lemma Obsidian plugin (`/run/media/sapiens/Development/Fundaments/Lemma`):
```markdown
---
title: "Theorem Vocabulary"
type: "theorem-vocabulary"
tags:
  - flashcards
  - theorem
  - vocabulary
generated_at: "2026-09-11T16:00:00.000Z"
terms_total: 24
---

# Theorem Vocabulary

---card---
### ephemeral ^fsrs-term-ephemeral
*/ɪˈfɛm(ə)rəl/*
> "The beauty of the cherry blossoms was ephemeral."
---
1. **adjective**: Lasting for a very short time.
2. **noun**: An ephemeral plant or insect.
```

- **Tagging**: Frontmatter `tags: [flashcards]` instructs Lemma to automatically index `Theorem Vocabulary` in the dashboard.
- **Card Structure**: `---card---` header and `\n---\n` separator matches `DataManager.ts:parseBasicCards`.
- **Persistent IDs**: `^fsrs-term-${term.id}` block ID preserves user's FSRS learning metrics (difficulty, stability, reps) across exports.

### 3.3 Idiomatic Book Highlights (`Theorem/Books/<Book>.md`)
Uses native Obsidian formatting:
- Native highlights: `> ==Selected quote==` instead of raw HTML `<mark style="...">`.
- Associated note: Markdown body directly beneath quote.
- Color and timestamp attributes kept cleanly in bullet points.
- No dead/unregistered deep links.

### 3.4 Reactive Automatic Sync Pipeline
- In `src/features/settings/Settings.tsx`, selecting a folder immediately calls `triggerVaultAutoSync({ immediate: true })`.
- In `src/core/lib/vault-sync.ts`:
  - Centralize `triggerVaultAutoSync()` with a 2-second debounce timer.
  - Subscribe to `useLibraryStore` (annotations added/edited/deleted) and `useVocabularyStore` (terms added/deleted).
  - Only sync when `settings.vault.enabled` and `settings.vault.vaultPath` is non-empty.
  - Status updates: Silently record `lastVaultSyncAt` and update UI status without blocking dialogs.
